# Идеологии — интерактивный образовательный сайт

Откройте `index.html` в браузере.

Особенность:
- исходная тема чёрно-белая;
- наведение на карточку меняет цветовую атмосферу;
- справа появляется краткое объяснение;
- темы фашизма и нацизма выполнены в тёмно-красной/кровавой гамме без использования нацистской символики;
- `Escape` возвращает исходное состояние.

Файлы:
- `index.html` — структура сайта
- `style.css` — дизайн
- `script.js` — интерактивность и данные идеологий
